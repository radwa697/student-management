# Student Management System

A full-stack web application designed to manage students, courses, departments, instructors, and enrollments through an organized and user-friendly interface.

## 📌 Project Overview

The Student Management System provides a practical solution for managing academic information in one centralized system.

The project consists of:

- A frontend application built with Angular and TypeScript.
- A backend REST API responsible for business logic, authentication, data management, and database operations.
- A MongoDB database for storing and managing application data.

## ✨ Features

- Student management
- Course management
- Department management
- Instructor management
- Enrollment management
- Authentication and authorization
- CRUD operations
- Duplicate-enrollment validation
- Frontend and backend API integration
- Error handling
- Middleware implementation
- Database integration
