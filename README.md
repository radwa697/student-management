# Student Management System

## Project Overview

Student Management System is a full-stack web application designed to manage students, courses, departments, instructors, and enrollments through an organized and user-friendly interface.

The project includes a frontend application for interacting with the system and a backend API responsible for business logic, authentication, data management, and database operations.

## Features

- Student management
- Course management
- Department management
- Instructor management
- Enrollment management
- Authentication and authorization
- CRUD operations
- Duplicate-enrollment validation
- Frontend and backend API integration
- Error handling and middleware

## Main Modules

- **Students:** Manage student information.
- **Courses:** Manage courses and course information.
- **Departments:** Manage academic departments.
- **Instructors:** Manage instructor information.
- **Enrollments:** Manage student course enrollments by semester and status, with duplicate-enrollment validation.
- **Authentication:** Provide secure access through authentication and authorization.

## Getting Started

### Backend

Open the `backend` folder, install the required dependencies, configure the database connection, and start the backend server.

### Frontend

Open the `frontend` folder, install the required dependencies, and run the Angular development server.

### Database

Configure the database connection according to the backend configuration before running the application.

## Project Goal

The goal of this project is to provide a practical student management solution while demonstrating full-stack development skills, including frontend development, backend APIs, database integration, authentication, CRUD operations, and API communication.
